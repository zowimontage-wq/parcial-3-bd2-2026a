# Cardinalidades

- Un **género** tiene muchas **películas** (1:N).
- Una **película** se programa en muchas **funciones** (1:N).
- Una **sala** alberga muchas **funciones** y tiene muchas **butacas** (1:N).
- Una **función** genera muchos **boletos** (1:N).
- Una **butaca** puede venderse en muchas funciones, pero **solo una vez por función** (1:N + UNIQUE).
- Un **cliente** puede tener muchas **ventas** (1:N, opcional).
- Una **venta** incluye muchos **boletos** (1:N).
